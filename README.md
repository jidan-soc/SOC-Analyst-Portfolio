# SOC Analyst Portfolio — JidanSec

**Focus:** SOC analysis · Threat detection · Incident response · Digital forensics · Blue team

This repository contains practical, documented **lab exercises using simulated data** to demonstrate entry-level SOC workflows. The work is educational and is not evidence of activity in a real company environment.

## Projects

| Project | Skills demonstrated | Status |
|---|---|---|
| [01 — Simulated Phishing Investigation](01-Phishing-Investigation/README.md) | Email triage, indicator review, risk assessment, response recommendations | Documented lab |
| [02 — Windows Authentication Log Triage](02-Auth-Log-Triage/README.md) | Log parsing, failed-login review, source-IP grouping, alert prioritization | Runnable Python lab |
| [03 — Incident Response Playbook](03-Incident-Response-Playbook/README.md) | Triage checklist, containment, evidence preservation, escalation | Playbook |
| [04 — SOC Alert Investigation Template](04-SOC-Investigation-Template/README.md) | Consistent investigation notes, timeline, impact and closure | Template |

## Quick start

1. Open a project folder and read its README before using the files.
2. For Project 02, use Python 3 on a computer or an Android Python environment that supports standard Python scripts.
3. Review the sample data and expected output in the project documentation.
4. Do not upload real personal data, company logs, credentials, tokens, or confidential information.

## Skills represented

- SIEM alert triage and event/log analysis concepts
- Phishing indicator review and incident documentation
- Authentication-event analysis and basic detection logic
- Incident severity, escalation, evidence preservation, and response workflow
- Python scripting for simple log triage

## Tools and environment

- Python 3 (Project 02)
- CSV and JSON-formatted simulated event data
- Markdown documentation
- Familiarity with Wireshark, Nmap, TCPdump, and Seceon SIEM is described in the candidate's CV; this repository does not claim that these tools were used in every project.

## Important integrity note

All sample events, IP addresses, email addresses, timestamps, and scenarios in this repository are synthetic and intended for learning. No real phishing email was sent, no production environment was accessed, and no real incident is claimed. Replace any placeholder with your own verified details only.
